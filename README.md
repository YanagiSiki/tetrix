# Tetrix

3D 俄羅斯方塊遊戲，使用 JavaScript + Three.js 開發。

## 技術棧

- **渲染**: Three.js (WebGL)
- **語言**: JavaScript / TypeScript
- **打包**: Vite

## 開發方式

本專案採用 vibe coding 工作流：

- **agy** (Google Antigravity CLI) — 主要 coding agent
- **OpenSpec** — 規格驅動開發，管理需求與設計
- **OpenClaw** — 監督、備份、記憶同步

## 專案結構

```
tetrix/
├── docs/          # 設計文件 & spec
├── src/           # 原始碼
├── openspec/      # OpenSpec 規格文件
└── README.md
```
